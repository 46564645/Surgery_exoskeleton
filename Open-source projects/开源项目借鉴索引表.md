# 开源项目借鉴索引表

## 使用边界

> 本表是项目自有的借鉴索引，不是第三方实现保证。当前规则以[系统架构蓝图](../Main_%20project/docs/system_architecture_blueprint.md)为准，尤其是5.7至5.11节的输出类型、动作暂停、故障恢复与参考差异。参考源码保持只读；所有改写量仅为粗略估计，不代表已完成复用或验证。

- 当前硬件边界：STM32F446RE；SHOULDER_SIDE 为 GIM6010-8 + GDS68；ELBOW 为裸 M3508 + C620。不得套用 P19 减速总成的数据或实现。
- 当前感知边界：暂不使用 IMU；肩、肘状态以电机编码器为主。M3508 编码器仅在当前 1:1、无滑移假设下暂作肘关节角度来源。
- 当前功能边界（2026-10-16）：以省力和自由跟随为主，连续重力补偿为基础；动作放大为可选后续扩展，根据编码器方向和速度介入。Lock通电位置保持已取消，不移植，也不作为其他功能前置；动作取消/停止、状态保护和遥测仍保留。力传感器 + HX711 只作辅助监测，不作为主要助力触发。
- “直接使用”指库、生成代码、工具或已经确定的功能语义可原样采用；“需要修改”指预计改写量不超过 55%；“自己编写”指项目代码仍需自行完成 55% 以上，但所列项目能减少分析、设计或局部实现工作。
- 每行最多列两个主参考。标成“思路借鉴”的项目不计入主参考，也不表示复制其源码。“拿走使用部分”无法确认时留空。
- 改写量是相对该模块最终项目代码的初步估计，不是对整个仓库的修改比例；硬件协议、控制参数和安全阈值仍须以实物资料和后续验证为准。
