# 临时实验目录

排障结束后计划删除的诊断代码、专用脚本、测试及使用说明，统一放在这里，每个实验一个子目录。

- 实验默认关闭，显式启用；业务控制逻辑不得依赖实验结果才能运行。
- 优先使用可选构建接入，删除实验目录并重新配置后，普通固件仍能构建。
- 不把实验逻辑放进 `main.c`，不修改第三方/HAL 源码，不改变既有输出许可或故障门控。
- 每个实验 README 说明入口、用途、开销、证据边界和删除步骤；实质进展仍只记录在项目 `development_schedule.md`。
- 可重建产物仍放固件 `build/`；临时采集默认保存在各实验自己的忽略目录。删除前将需要长期保留的真实证据按项目原有规则归档。
- 本轮未迁移已有验收测试、历史证据或正在使用的 S2/S3 诊断功能；它们的生命周期需分别确认。
