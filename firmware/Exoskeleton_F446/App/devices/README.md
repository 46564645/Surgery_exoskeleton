# devices

L2设备适配通过L1平台接口收取原生数据，不包含HAL句柄或应用策略。新增源文件须显式加入顶层 CMakeLists.txt 的 target_sources 和头文件目录配置。

当前 `c620_feedback.c/.h` 只解析肘侧标准DATA/DLC8反馈，ID由 `Core/Inc/s2_config.h` 集中配置；ID1来自2026-10-01实物0x201快照。位置为电机转子单圈rad、速度为转子rad/s；不是肘关节坐标，不应用未知传动比/方向/零位，不猜反馈电流A/计数比例。原始有符号电流计数和温度保留。

时间戳来自CAN接收，错误ID/DLC、角度越界、排队超时或乱序帧不刷新。100ms为当前台架暂定新鲜度阈值（约100个观察到的1kHz周期），阈值边界与uint32回绕由主机测试覆盖；尚未板上验证。超时保留缓存但清除有效/在线标记，必须新有效帧恢复，不因时间戳回绕恢复旧缓存。

`hx711.c/.h` 缓存 HX711 通道A增益128的有符号24位原始码、序号、接收时间和饱和标志，经L1 `board_hx711.c` 非阻塞读取。2026-10-17 加入当前安装位置的452 g单点临时换算：`F_N = (zero_raw - raw) / 45127.7057`，默认零点144811.46。`Hx711_Tare()` 取最新有效样本作RAM零点，不阻塞等待，初始化恢复默认零点。无样本、饱和或样本年龄≥500 ms时，力值无效且拒绝去皮；原始码仍保留供排查。仅作10 SPS辅助监测，不进入控制或安全判断，回零与多点线性未验证。GDS68适配见`gds_feedback.c`。
