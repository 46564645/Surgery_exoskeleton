# S2 方案取舍

- 采用现有auto-embedded组织任务，embeddedskills作为按需调用的工具；不迁移工程或创建另一套进度日志。
- bxCAN接收中断只搬运帧，主循环限量解析：沿用已有非阻塞调度，比在ISR解析协议更容易保持串口响应。无需CAN DMA或RTOS。
- 首先仅接收驱动器周期反馈。若GDS实物未启用周期反馈，先读出版本/通信配置，再确定已核实的只读查询或周期配置步骤；不套用参考库的任意发送接口。
- 分别调通肩侧GDS68、肘部C620后再同时观察。电源未测不影响离线开发准备，但阻塞驱动器上电。
- 双路分别记录原始数据、单位和时间戳。S2先提供转子观测，不将未经验证的传动倍率/方向直接命名为关节角度。
- 暂不扩展HX711、IMU、控制算法或PC上位机；直接利用S1串口命令读取摘要。
