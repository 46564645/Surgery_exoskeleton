# S5 肘部与双关节 FOLLOW 最小功能演示

日期：2026-10-11，2026-10-12 更新。当前 `task.json` 为 `EXECUTE`。R2 肘短脉冲已有两次轻微屈肘的现场观察；R4 `2 A` FOLLOW 曾有一次非零目标及正常停止，最近 `4 A` FOLLOW 只有短时出力感受，随后进入故障，未取得有辅助力读数或本轮正常停止。用户决定先收束肘单轴、转入双关节联动。R5 双轴隔离镜像已构建、刷写并独立读回；首次准备被拒，第二次取得两轴 RAM 零位后在网关 Prepare 提交前故障，均未启动 FOLLOW。以下双轴目标尚无实物通过结论。

## 需求与验收顺序

1. **肘 S3 有限动作记录。**裸 M3508/C620 在独立 CAN2 上已有 R2 短脉冲的两次轻微屈肘观察；用户口述电机与肘关节同轴直连、传动比 1:1，并在断电手动改变肘角时报告同步、未见打滑。它们不足以解释后续 R4 `+4 A` 启动时的伸直感受，肘输出方向仍在双轴首次窗口中观察。发送零电流不等于实物停妥，需目视静止；异常/断连的软件撤权和可及的 24V 切断融入现场步骤，未测失效方式保留未测。
2. **肘 FOLLOW 已做的有限观察。**肩侧固定并承托时，R4 `2 A` 有一次正常停止，最新 `4 A` 窗口短时出力后故障，未取得有辅助力数值、手动变姿态后持续跟随或本轮正常停止。用户选择先转双轴，不重复单轴测力。没有本机转矩常数/传动标定时，不把电流目标或反馈称为关节 Nm 或定量减负。
3. **低姿态双轴演示。**在同一短会话中让肩、肘两条局部候选共同许可；肩为 GDS68 转子 Nm，肘为 C620 A。先在肩垂臂基准及选定肘姿态取各自 RAM 零位，再由人手动将肩移入相对 20°–30° 工作区，肘保持在其会话零位附近 ±5°。一次现场观察两轴主观支撑、手动小幅变姿态后继续跟随、正常停止；肘输出方向在该窗口中观察，异常则停止并记录。任一关键反馈、CAN、调度、停止链异常，共同撤销两轴许可；正常取消两轴都停止，无旧候选重放。这只是受限个人台架 P0 双轴协调演示，不要求先完成完整三维装配坐标和质心测定。
4. **随后合并测具体数值。**功能演示完成后再测肩、肘与双轴同姿态扶持力，并追查 S4 助力段最大约 2.51°角度变化、速度门物理余量；必要时补完整三维装配坐标、质量和质心以建立精确模型。定量净减负不作为前述最小功能的先决条件，也不得把未测写成通过。

## 输入输出和约束

- 输入是带时间戳的 GDS68/C620 真实反馈，按设备边界转换成明确 rad、rad/s；输出分别为肩转子 Nm、肘命令 A，候选只由主循环计算，经 `SafetySupervisor` 和唯一 `OutputGateway` 否决与发送。C620 0–8191 单圈值不可直接伪装连续肘关节角；R1 已加入 RAM 会话零位、受限小区间跨零及跳变拒绝的软件路径，但现场方向/滑差和可用范围仍待小输出核对。
- 沿用 STM32F446RE/HAL/CMSIS、裸机静态调度、CAN1 肩/CAN2 肘及现有接口；不新增 IMU/HX711 快速控制、SHOULDER_BACK、P19、FreeRTOS 或位置自动定位。`main.c` 只编排，ISR 不做控制计算。
- 活动生产 profile 默认输出关闭。R5 隔离候选的肩侧部分沿用 S4 已观察的低姿态配置：增益 `0.36`、转子帽 `40 mNm`、速度门 `40°/s`、相对零位角域 `20°–30°`；肘部另设会话零位 `±5°`、`20°/s`、不超过 `2 A` 的电流指令帽。C620 协议 ±20 A 不是项目运行限值。先前 `+2 A` 轻微屈肘口述与 `+4 A` 启动时朝伸直方向回一下的感受不一致，肘输出方向在 R5 冻结与首次窗口中仍按未确认处理，不从肩侧参数推定。
- S4 已按用户选定范围结束，具体力值待 S5 后测。复用条件未变的旧证据，不重复肘单轴微测试；现场把具体镜像、独立读回、承托、限值、短会话和即时断电安排进同一必要窗口，不拆成多轮形式化门槛。双轴阶段不设置测力提示音或读数步骤；出错保留当次记录并查明根因，不盲改参数或代码。
- 本轮不做 S6 Lock、S7 Amplify、全姿态三维补偿、人体/临床验证或大型全故障矩阵。ExoKit/ARMin/GALAXEA/SymPyBotics 的参数和效果均不视作本机事实。
