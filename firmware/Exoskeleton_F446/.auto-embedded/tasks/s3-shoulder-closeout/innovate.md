# 2026-10-05追加：电动摆位测角的路线比较

| 路线 | 当前适用性 | 判断 |
|---|---|---|
| 直接把10传给旧shoulderpulse或延长转矩TTL | 旧接口是mNm/ms且没有位置终点/保持，100ms和±0.01转子包络不足以表示10° | 不采用；单位、功能和现场条件不匹配 |
| 复用驱动内置位置控制，通过项目唯一输出入口增加有限摆位/保持 | 厂家有位置协议，ExoKit有目标/零偏/符号/到位语义；需补类型化位置请求、原地准备读回、限制和有期限会话 | 选为候选路线；先PLAN审查，机械方向/比例和本机读回仍须落实 |
| 从零写STM32位置PID，或PC持续直接控制USB | 无当前调参/模型依据，PC旁路项目输出门控，新增控制环扩大范围 | 本轮不采用 |

“停住供测量”按有限时长的受控位置保持设计，到期/取消/故障进入IDLE；若实际承托足以维持姿态可提前撤权，但不能把IDLE写成主动保持。有限定位不扩展为FOLLOW/Lock或自动连续动作。
